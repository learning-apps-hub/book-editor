# Book Editor

A web app for reading a picture book, editing its words in several languages,
adding comments, and sending only the changes back to the author.

Status: under construction.

- File formats (book file, changes file, Library): [docs/book-file-format.md](docs/book-file-format.md)
- Made-up sample book: `python3 tools/make_sample.py` writes `site/samples/` and `_build/*.book.zip`
- Format check: `node tools/check_fingerprint.mjs`
